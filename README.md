# Vaccination Data Analysis and Visualization

End-to-end public health analytics project using Python, MySQL, SQL, and Power BI.

## Project Overview

This project analyzes synthetic vaccination and disease data to understand:

- Vaccination coverage trends
- Disease incidence and reported cases
- Vaccine introduction patterns
- Dose drop-off
- WHO regional disparities
- Resource allocation priorities

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- MySQL
- SQL
- Power BI

## Project Workflow

1. Data cleaning and validation
2. Exploratory Data Analysis
3. SQL database design
4. SQL analytical queries
5. Power BI dashboard development
6. Reporting and insights

## Key Findings

- Average vaccination coverage: 78.85%
- Average disease incidence rate: 19.86
- Total reported cases: approximately 53M
- Vaccine introduction rate: 86.62%
- Vaccination coverage declined around 2020 and recovered afterward
- Disease incidence generally declined over time
- Tuberculosis had the highest reported case burden in the synthetic dataset
